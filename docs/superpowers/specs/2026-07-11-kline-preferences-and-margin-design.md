# K 线计算上下文、全局偏好与两融余额修复设计

## 背景

当前详情图只展示用户选择的 260、520、1000 或全部 K 线。个股接口会在完整周期历史上计算既有服务端指标，再截取可见数据；前端自定义均线则只使用已截取的可见数据计算，导致 MA200 在 260 根视图的前 199 根为空。指数与个股的计算路径也不完全一致。

现有前端分别使用多个 `localStorage` 键保存部分设置，但缺少统一、可迁移的 K 线偏好模型。两融数据在本地 Tushare 扩展库中存在，不过 Market Pulse 按市场最新交易日精确查询；当 Tushare 两融数据晚一个交易日发布时，界面会把缺失值误显示为 `0.00`。

## 目标

1. 指数和个股的指标计算都能使用可见窗口之前的本地历史数据，图表仍只展示用户选择的范围。
2. 所有 K 线控制项作为一套全局偏好跨指数、个股和应用重启保留。
3. 两融余额使用不晚于市场日期的最近有效数据，并明确标注数据日期；真正缺失时显示 `--`。

## 非目标

- 不按股票或指数分别保存设置。
- 不改变 provider CSV 的存储格式或最大图表显示上限。
- 不为本任务增加新的市场数据来源。
- 不把整个股票历史无条件发送给浏览器。

## K 线数据与指标计算

### 可见数据和计算上下文

股票与指数详情 API 保留现有可见数据字段及限制语义，同时提供独立的、长度受控的计算上下文。计算上下文包括可见窗口之前的历史 K 线，前端在完整上下文上计算自定义 MA、MACD 等前端指标，再裁剪为可见窗口绘制。

上下文长度由已保存的指标参数决定，并设置安全上限。MA 至少取得最长均线周期所需的前置数据；MACD 取得足够的稳定预热数据。服务端原本在完整数据上计算的 KDJ、Min J、知行覆盖层与十三转继续保留完整历史语义。

周 K 和月 K 必须先在完整日线历史上完成周期聚合，再从聚合结果生成计算上下文和可见窗口。不能先截取日线再聚合。

API 继续返回 `limit`、`total_bars` 和 `max_limit`。可见数组的长度不得因预热数据而改变，避免导出、界面计数或现有消费者误把预热数据当成可见数据。

### 前端绘图

前端把计算上下文按日期升序用于指标计算，只把可见日期对应的结果交给 ECharts。若旧服务端未返回计算上下文，前端回退到当前可见数组，保持兼容。

## 全局 K 线偏好

新增版本化的 `quantKlinePreferences` JSON 对象，统一保存：

- 详情周期：日 K、周 K 或月 K；
- 显示范围：260、520、1000 或全部；
- MA 周期、颜色和启用状态；
- 十三转启用状态；
- MACD 快线、慢线、信号线参数和启用状态；
- 首页指数概览月份范围。

所有指数和个股共享这套偏好。每次用户操作后立即保存；应用启动时加载、校验和规范化，再同步到控件。异常或损坏的本地值回退到安全默认值。

首次加载新结构时，若 `quantKlinePreferences` 不存在，则迁移现有的 `quantMaSettings`、`quantMacdSettings`、`quantShowSequenceMarkers` 和 `quantStockChartLimit`。迁移后以新对象为权威来源；旧键只用于一次兼容读取，不再产生互相覆盖。

如果当前界面没有某项显隐控制，则不凭空增加无用控件；现有可操作的显隐状态必须持久化。详情周期在打开下一只股票或指数时沿用上一次全局选择。

## 两融余额日期对齐

两融余额继续使用 Tushare `margin` 数据集。对于市场日期 D：

1. 查找 `trade_date <= D` 的最近一个有数据日期 M；
2. 汇总 M 当日各交易所的 `rzrqye`，缺失时才回退到 `rzye + rqye`；
3. 环比查找严格早于 M 的上一条实际两融数据日期 P；
4. 卡片返回并展示 M，例如 `截至 07-08`；
5. 若不存在 M，值与环比均为 `null`，界面显示 `--`，不得转换为零。

Market Pulse 缓存签名必须包含实际使用的两融日期或相应源数据签名，保证新数据写入后旧缓存失效。

## 错误处理与兼容性

- localStorage 不可用时保留内存默认值并记录非阻断警告。
- 无足够预热历史时只对确实无法计算的早期点返回空值。
- API 新字段为向后兼容增量，不移除现有字段。
- 两融权限警告继续作为扩展数据警告展示，不影响主价格同步。

## 测试与验收

先写失败测试，再实现：

1. 260 根可见数据的第一根在拥有更早历史时已有 MA200；
2. 周 K、月 K 在完整历史聚合后预热，且可见长度仍符合 limit；
3. 新偏好对象能保存和恢复全部控制项；
4. 旧键能迁移且不会在启动时覆盖新偏好；
5. 股票与指数共用同一全局偏好；
6. 市场日期晚于两融日期时使用最近有效两融余额及其上一有效日环比；
7. 真正缺失的两融数据渲染为 `--`；
8. JavaScript 语法、相关 pytest、完整 pytest 和 `git diff --check` 通过；
9. 启动本地应用，关闭十三转并修改其他控制项，重启后验证状态恢复；检查均线首屏和两融日期标注。
